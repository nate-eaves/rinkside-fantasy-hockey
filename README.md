# Rinkside Fantasy Hockey

A manual import fantasy hockey dashboard with a refreshed news feed.

## Dashboard

After enabling GitHub Pages for this repository, visit:

https://nate-eaves.github.io/rinkside-fantasy-hockey/

The news snapshot is refreshed every 15 minutes by GitHub Actions. Use the **Trending News** tab to refresh the page view and maintain a local player watchlist.

CSV imports and the watchlist are kept in the browser and are not uploaded to GitHub.
